2. إدارة المحتوى

  • يتحكم فريق المجمع في محتوى الموقع بالكامل عبر لوحة التحكم دون أي تدخل تقني.
  • يمكن حفظ النشاط كمسوّدة ثم نشره لاحقاً — لا يظهر على الموقع العام حتى يُنشر.
  • التغييرات المنشورة تنعكس فوراً على الموقع.

3. الاستضافة والأمان

  • يعمل المشروع على خادم Node.js يخدم الموقع العام ولوحة التحكم معاً.
  • NGINX يعمل أمام خادم Node.js كبوابة دخول ويتولى توجيه الطلبات إليه.
  • لوحة التحكم محمية بمصادقة ومستبعدة من محركات البحث.

5. المنافذ المفتوحة واتجاه حركة البيانات

يُرجى التأكد من أن جدار الحماية الخاص بالمجمع — إن وُجد — يسمح بحركة البيانات الواردة والصادرة وفق الجدول التالي:

6. بيانات الوصول إلى الخادم

لإتمام عملية الإعداد والنشر، يحتاج الفريق التقني إلى بيانات الوصول التالية من المجمع:

  • عنوان IP الثابت للخادم.
  • اسم المستخدم وكلمة المرور أو مفتاح SSH للوصول إلى الخادم.
  • أي صلاحيات إدارية مطلوبة (sudo) لتثبيت البرامج وضبط الإعدادات.

6. النطاق وشهادة SSL

  • يوفر المجمع اسم النطاق ويوجّه سجل DNS الرئيسي (A Record) إلى عنوان IP الثابت للخادم.
  • شهادة SSL مقدَّمة من المجمع وتُثبَّت على الخادم.

7. النشر والتسليم

  • الكود مخزَّن في مستودع Git خاص يُسلَّم للمجمع عند الانتهاء.
  • النشر يتم عبر سحب آخر إصدار من المستودع على الخادم وإعادة تشغيل خادم Node.js.
  • يُوثَّق إجراء النشر الكامل ويُسلَّم ضمن حزمة التسليم النهائية.
