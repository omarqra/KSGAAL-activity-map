5. التوافق وعدم فقدان البيانات

  • الهجرة إضافية فقط — لم يُحذف أو يُعد تسمية أي عمود قائم. الأعمدة القديمة (name, dateText, dateParsed) تبقى وتُملأ تلقائياً.
  • الموقع العام يواصل القراءة من الأعمدة القديمة، فلا ينكسر عرض الكرة أثناء الانتقال.
  • الحقول الجديدة كلها اختيارية على مستوى الواجهة؛ النموذج الحالي يعمل دون تغيير سلوك المستخدم.
  • الـ182 نشاطاً الحالية حصلت على titleAr وstartDate عبر backfill (تحقّق آلي ناجح).

6. خطوات ما قبل الرفع (موصى بها)

  • تشغيل النظام يدوياً (npm run dev) والتحقق بصرياً من: إنشاء/تعديل نشاط بالحقول الجديدة، رفع صورة، ظهور المعرض على الكرة، رسالة تعارض عند تعديل متزامن.
  • جدولة سكربت النسخ الاحتياطي (npm run db:backup) يومياً على الخادم.
  • اعتماد القيم الافتراضية القابلة للنقاش: مدة الجلسة، نسبة 16:9 للصور، نطاق 50–150 كلمة للوصف.
