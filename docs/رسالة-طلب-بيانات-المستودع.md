# رسالة إلى فريق التقنية بالمجمع — طلب بيانات مستودع الصور

**الموضوع:** مشروع Arabic-Around-theWorld — طلب بيانات الدخول لمستودع OCIR لإكمال النشر على البيئة التطويرية

السلام عليكم ورحمة الله وبركاته،

بعد استلامنا بيانات البيئة (Agent pool، Service connection، Environment)، أكملنا تجهيز خط النشر (CI/CD Pipeline) للمشروع، وتحققنا ميدانياً من جاهزية البيئة، ونعرض عليكم النتائج والمطلوب المتبقي.

## أولاً: ما تم التحقق منه وهو جاهز

| البند | النتيجة |
|---|---|
| وكيل البناء `KMO-ANSB-TOOL01` | يعمل، ونظامه Linux، وDocker مثبّت عليه وصالح للاستخدام |
| الاتصال `development-AATW` | يعمل، ويصل إلى الـ cluster بنجاح |
| الصلاحيات داخل مساحة `dev` | كاملة وكافية لإنشاء جميع الموارد المطلوبة للنشر |
| بناء التطبيق على الوكيل | مكتمل بنجاح |

## ثانياً: المطلوب لإكمال النشر

ينقصنا **بند واحد فقط**: بيانات الدخول إلى مستودع الصور لديكم `jed.ocir.io/axzbw7rafu2r`، وتحديداً:

1. **اسم مستخدم OCIR** — بالصيغة `axzbw7rafu2r/<اسم-المستخدم>`، أو بصيغة الدخول الموحّد إن كان الحساب اتحادياً.
2. **Auth Token** — ويُولَّد من Oracle Cloud Console خلال أقل من دقيقة عبر:
   `Profile ← My profile ← Auth tokens ← Generate token`
3. **اسم المستودع الفرعي** الذي نرفع إليه صورة التطبيق تحت `axzbw7rafu2r` (نقترح `aatw/ksgaal-activity-map` أو ما ترونه مناسباً وفق تسميتكم المعتمدة).

ولا نحتاج منكم أي شيء آخر: لا إنشاء Service Connection جديد، ولا تهيئة سرّ سحب (imagePullSecret) داخل المساحة — خط النشر يتكفّل بالأمرين ذاتياً من هاتين القيمتين.

## ثالثاً: لماذا لا يوجد بديل

اختبرنا إمكانية استخدام مستودع خارجي مؤقتاً لتفادي الانتظار، وتبيّن أن عُقد الـ cluster لا تملك اتصالاً صادراً بالإنترنت:

```
Failed to pull image "ghcr.io/...": pinging container registry ghcr.io:
Get "https://ghcr.io/v2/": dial tcp 20.233.83.147:443: i/o timeout
```

وهو سلوك سليم أمنياً ومتوقّع، لكنه يعني أن مستودعكم الداخلي هو المسار الوحيد الممكن، وأن النشر متوقف فعلياً على هاتين القيمتين.

## رابعاً: استفسار

لاحظنا وجود اتصال بـ SonarQube مخصّص للمشروع. هل اجتياز بوابة الجودة (Quality Gate) شرط لإكمال النشر، أم أن الفحص للاطّلاع فقط؟ لنُدرجه في خط النشر بالشكل الصحيح.

نقدّر لكم تعاونكم، وفي انتظار ردّكم لإتمام أول نشرة على البيئة التطويرية.
